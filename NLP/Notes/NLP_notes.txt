We have few preprocessing techniques to covert the text to number. Below  all techniques for converting text into numerical vectors in NLP.
1) Counter Vector (Also called Bag of Words (BoW))
explain : It counts how many times each word appears in a document.

2) TF-IDF Vector (Term Frequency × Inverse Document Frequency)
explain : It gives more importance to words that are important in a particular document but not common across all documents.(How important is this word to this document?)

3) Hash Vector
explain : Hashing Vectorizer uses a hash function to convert words into positions in a fixed-size vector.

#### LSTM ####

LSTM uses Sigmoid and Tanh because they help it control and manage information flowing through the network.

Sigmoid = Control/Gate → decides HOW MUCH information passes.
Tanh = Information → decides WHAT information to store.

@@@@@
Sigmoid converts any value into a range between 0 and 1.

Positive value → output closer to 1 ex: +5 → 0.99, +1 → 0.73
Zero → output 0.5
0 → 0.5
Negative value → output closer to 0 ex: -1 → 0.27, -5 → 0.01

Positive → 1 | Zero → 0.5 | Negative → 0

Formula: Sigmoid(x) = 1 / (1 + e⁻ˣ)


@@@@@
Tanh converts values into a range between -1 and +1.

Positive value → output closer to +1 ex: +1 → 0.76,  +5 → 1
Zero → output 0
0 → 0
Negative value → output closer to -1 ex: -1 → -0.76, -5 → -1

Positive → +1 | Zero → 0 | Negative → -1

Tanh = tells the model whether information is positive, negative, or neutral.

##############
LSTM = Sigmoid controls + Tanh transforms information.

Sigmoid will help to get how much % Long term to remember.

Tanh will help to get it is potential long term memory. the result will consider whether will take the value to long term or not.

SoftMax
Softmax converts multiple values into probabilities between 0 and 1, where all probabilities add up to 1.
Softmax converts logits/scores into probabilities (0–1), and the probabilities add up to 1. The highest probability is the most likely prediction.

Example:
Scores:     2.0   1.0   0.5
Softmax:    0.63  0.23  0.14
The highest probability is usually selected as the predicted class.

Where is Softmax used?
Mainly in the output layer of a classification model
Used when there are multiple classes
In a Transformer decoder, Softmax converts the output scores (logits) into probabilities for the next token. 


In the Transformer Decoder, Softmax converts token scores into probabilities for the next token. During training, the loss and backpropagation use these probabilities to calculate gradients, which the optimizer uses to update the model's weights.

Teacher Forcing

Teacher Forcing in Transformer Decoder
Teacher forcing means giving the decoder the correct previous token during training instead of giving it the token that the model predicted.

Teacher forcing is a training technique where the decoder receives the actual previous token as input instead of its own predicted token.

Important: Teacher forcing is mainly a training technique. During actual inference/generation, the decoder generally uses its own previously generated token.

Example:
Suppose the correct sentence is:
I am learning AI

During training:
Decoder input       → Predict
<START>             → I
<START> I           → am
<START> I am        → learning
<START> I am learning → AI

Even if the model predicts the previous word incorrectly, we still give the correct previous word as the next input.

The main purpose of teacher forcing is to help the decoder learn faster and more accurately by giving it the correct previous word during training.


Important notes:
1) In LSTM long term memory (Cell state) don't operate with Weight and Bias W B, that how is over comes the Exploding and Vanishing issue on RNN.
2) In Shot team memory (hidden state) have W and B weight and Bias. Without W,B the learning process won't happen. so in shot team it have W and B
