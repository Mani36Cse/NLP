NLP Text Classification
📌 About the Project

This project focuses on Natural Language Processing (NLP) and text classification.

The goal is to compare different text vectorization techniques and machine learning algorithms to find the best-performing model.

🔹 Vectorization Techniques
CountVectorizer
TF-IDF Vectorizer
HashingVectorizer
🔹 Machine Learning Algorithms
Logistic Regression
Linear SVM
Multinomial Naive Bayes
Complement Naive Bayes
SGD Classifier
K-Nearest Neighbors (KNN)
🔄 Workflow
Text Data
   ↓
Text Preprocessing
   ↓
Train / Test Split
   ↓
Vectorization
   ↓
Machine Learning
   ↓
GridSearchCV
   ↓
Model Evaluation
   ↓
Best Model

🧹 Preprocessing

The text is cleaned before training:

Convert text to lowercase
Remove URLs
Remove special characters
Remove extra spaces
Remove stop words where required
🔍 Model Tuning

GridSearchCV is used to find the best hyperparameters for the models using cross-validation.

The project compares different combinations of:

3 Vectorizers × 6 Algorithms = 18 Combinations

📊 Evaluation

Models are evaluated using:

Accuracy
Precision
Recall
F1 Score
Confusion Matrix

Run the Jupyter Notebook:

jupyter notebook
